# Glowly — AI Voice Booking & Multi-Tenant Salon SaaS Platform

Built on branch: `Salon-Sched-App`

## Stack
- **Frontend:** Next.js 14, React 18, TypeScript, Tailwind CSS
- **AI Voice:** OpenAI GPT-4o + Twilio Voice (integration-ready)
- **Design:** Dark mode, glassmorphism, brand gradient (purple → pink)

## Pages Built
- `/` — Landing page with hero, search, featured pros, AI voice section
- `/marketplace` — Browse all professionals with filters
- `/pro/[id]` — Professional profile with booking panel
- `/book/[id]` — 4-step booking flow
- `/pro/dashboard` — Pro business dashboard (KPIs, schedule, AI stats)
- `/pro/register` — Pro signup + pricing tiers
- `/ai-voice` — AI voice receptionist feature page
- `/login` + `/signup` — Auth pages

## PRD: AI-Powered Beauty & Wellness Booking Platform
Targeting 1M+ users. Features: Online booking, AI voice receptionist, CRM, marketplace, payments, website builder.
